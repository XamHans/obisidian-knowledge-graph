## Why It Matters
- Memory strategy determines whether agents remain coherent across turns and sessions without accumulating noisy or stale context.

## Sub-Concept Map
- Working memory for immediate task state.
- Episodic memory for prior interactions.
- Semantic memory for durable knowledge facts.
- Retrieval policy and memory freshness controls.
- Privacy and retention constraints.

## Playbook Moves
- Separate transient run-state from long-lived memory stores.
- Add freshness and relevance filters before memory retrieval.
- Periodically compact and prune stale memory entries.
