- Separating planning, execution, and verification reduces compounding errors in complex agent tasks.

## Sub-Concept Map
- Role separation across agent steps
- Verifier criteria and stop conditions
- Iterative correction loops
- Cost-latency control per stage

## Playbook Moves
- Use a small planner output contract before any tool actions.
- Run verifier checks on intermediate artifacts, not only final answers.
- Cap replanning loops to contain latency and cost.
