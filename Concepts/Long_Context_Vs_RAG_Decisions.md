- Choosing between very long context and retrieval pipelines is a core architecture decision impacting cost, latency, and reliability.

- Cost and latency budget constraints
- Grounding and citation requirements
- Operational complexity tradeoffs

## Playbook Moves
- Default to RAG when freshness, provenance, or corpus scale are primary constraints.
- Use long-context mode for bounded tasks with stable source sets.
- Benchmark both paths on identical tasks before committing architecture.
