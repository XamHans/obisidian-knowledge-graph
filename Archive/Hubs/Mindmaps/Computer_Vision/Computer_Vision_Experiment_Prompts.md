# Computer Vision Experiment Prompts

## Beginner
- Train a baseline image classifier and compare error classes across top-5 confusion pairs.
- Evaluate object detection precision/recall as IoU threshold changes.
- Build a small OCR pipeline and benchmark quality on noisy scans.

## Intermediate
- Compare ViT vs CNN representations on the same dataset and analyze failure patterns.
- Measure synthetic data impact on rare-class detection.
- Build a video understanding benchmark with temporal consistency checks.

## Advanced
- Design a safety evaluation sheet for vision model deployment risks.
- Create a monitoring setup for tracking drift in camera/domain conditions.
- Build an ablation matrix for segmentation quality vs annotation granularity.

## Execution Rule
- Log dataset assumptions, metrics, edge cases, and production implications after each run.
