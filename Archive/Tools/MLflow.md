# MLflow

## Definition
- MLflow is an open-source platform for experiment tracking, artifact logging, model packaging, and model registry workflows.

## Capabilities
- Log parameters, metrics, artifacts, and models.
- Compare experiment runs.
- Register and manage model versions.
- Integrate with Azure ML tracking and registry workflows.

## AI-300 Role
- MLflow is the concrete tracking and model-management primitive behind reproducible training and model lifecycle operations in Azure ML.
