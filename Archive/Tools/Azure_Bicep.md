# Azure Bicep

## Definition
- Azure Bicep is a domain-specific language for declaratively deploying Azure resources as infrastructure as code.

## Capabilities
- Define Azure resources, parameters, modules, and outputs.
- Deploy repeatable environments from source-controlled templates.
- Support reviewable infrastructure changes in CI/CD workflows.

## AI-300 Role
- Azure Bicep is the concrete infrastructure-as-code primitive behind repeatable Azure ML and Microsoft Foundry resource deployment.
