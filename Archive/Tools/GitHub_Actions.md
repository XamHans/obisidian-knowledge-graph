# GitHub Actions

## Definition
- GitHub Actions is a workflow automation and CI/CD platform used to run jobs from repository events, pull requests, schedules, and manual triggers.

## Capabilities
- Run Azure CLI, SDK, tests, evaluation scripts, and deployment commands.
- Automate Azure ML training jobs and model deployments.
- Automate GenAIOps prompt evaluation, prompt flow workflows, and promotion gates.

## AI-300 Role
- GitHub Actions is the concrete automation primitive behind MLOps and GenAIOps CI/CD workflows.
