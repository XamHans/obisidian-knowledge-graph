# Azure Application Insights

## Definition
- Azure Application Insights is an observability service in Azure Monitor used to collect application telemetry, traces, logs, metrics, and performance data.

## Capabilities
- Endpoint and application metrics.
- Logs and KQL query analysis.
- Trace collection for GenAI applications and agents.
- Integration with dashboards, alerts, and monitoring workflows.

## AI-300 Role
- Application Insights is the concrete observability primitive behind endpoint monitoring, GenAI tracing, token/cost monitoring, and operational diagnostics.
