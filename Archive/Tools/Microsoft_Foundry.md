# Microsoft Foundry

## Definition
- Microsoft Foundry is Microsoft's platform for building, deploying, evaluating, observing, and operating GenAI applications, models, agents, prompts, and connected AI resources.

## Capabilities
- Foundry projects and resources.
- Model catalog and foundation model deployment.
- Prompt flow, prompt variants, evaluation, observability, tracing, and agent workflows.
- RBAC, private networking, Application Insights integration, and CI/CD patterns.

## AI-300 Role
- Microsoft Foundry is the primary operational substrate for the GenAIOps side of AI-300.
