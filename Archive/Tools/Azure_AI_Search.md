# Azure AI Search

## Definition
- Azure AI Search is Microsoft's managed search and retrieval platform for keyword search, vector search, hybrid search, semantic ranking, indexing, and integrated vectorization.

## Capabilities
- Vector indexes and vectorizers.
- Hybrid keyword-plus-vector retrieval.
- Semantic ranking and scoring.
- RAG retrieval over indexed enterprise content.

## AI-300 Role
- Azure AI Search is the concrete retrieval layer behind RAG optimization, embedding choices, hybrid search, semantic ranking, and vectorization topics.
