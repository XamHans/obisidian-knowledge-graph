# Azure Machine Learning

## Definition
- Azure Machine Learning is Microsoft's managed platform for building, training, tracking, registering, deploying, monitoring, and operating machine learning models.

## Capabilities
- Workspaces for organizing assets and operations.
- Data assets, datastores, compute, environments, components, jobs, pipelines, registries, models, online endpoints, and batch endpoints.
- MLflow integration for tracking and model management.
- Monitoring, responsible AI, identity, networking, and CI/CD integration points.

## AI-300 Role
- Azure ML is the primary operational substrate for the MLOps side of AI-300.
