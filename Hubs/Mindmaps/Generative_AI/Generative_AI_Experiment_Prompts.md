# Generative AI Experiment Prompts

## Beginner
- Compare two prompt templates for the same task and score output consistency.
- Add structured output constraints to a baseline prompt and measure parse success rate.
- Test two decoding settings and document quality vs variability tradeoffs.

## Intermediate
- Build a hallucination analysis set and test mitigation strategies.
- Evaluate long-context performance with key facts placed at beginning, middle, and end.
- Compare two model-routing rules for latency and quality.

## Advanced
- Design an alignment evaluation rubric for unsafe or policy-sensitive outputs.
- Build a structured output validation-and-repair loop with strict schema checks.
- Run a prompt injection red-team pass and define concrete defense gates.

## Execution Rule
- Publish rubric, failure taxonomy, and rollback criteria for each experiment.
