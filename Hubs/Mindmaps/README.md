# Mindmap Exports

This folder contains markmap-ready Markdown exports grouped by major AI topic.

## How to use
- Open https://markmap.js.org/repl
- Paste the content of any `*_Map.md` file.
- Use `*_References.md` for Obsidian note links and deeper study paths.
- Use `*_Experiment_Prompts.md` to convert map nodes into practical exercises.
