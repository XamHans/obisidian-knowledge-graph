# Machine Learning Experiment Prompts

## Beginner
- Build one binary classifier baseline and document the full train/validation/test split rationale.
- Compare two feature engineering variants and measure precision/recall impact.
- Create a simple calibration plot and explain where confidence is over- or under-estimated.

## Intermediate
- Run a bias-variance study by varying model complexity on the same dataset.
- Track concept drift over time on a rolling window and design alert thresholds.
- Use an LLM-as-judge rubric for model output quality and compare with human scoring on a sample.

## Advanced
- Build a reproducible experiment tracking template that captures dataset version, hyperparameters, and metrics.
- Evaluate when self-supervised pretraining helps downstream accuracy for limited labels.
- Design a policy for retraining triggered by data drift and calibration degradation.

## Execution Rule
- For each prompt, publish: hypothesis, setup, metrics, result, failure analysis, next action.
