# Start Here: The AI Engineer Knowledge Graph

Welcome. The knowledge graph is the shared technical map for this community:

https://github.com/XamHans/obisidian-knowledge-graph

Use it when you want to learn the concepts behind production AI apps, RAG, agents, MCP, evals, and deployment tools.

## Best Way To Use It

1. Open the repo in GitHub or clone it into Obsidian.
2. Start with `START_HERE.md`.
3. Then open `Hubs/AI_Concept_Universe.md` for the full map.
4. Choose a path:
   - AI app builder: `Hubs/Generative_AI.md`
   - RAG engineer: `Hubs/RAG.md`
   - Agent engineer: `Hubs/AI_Agents.md`
   - MCP/tool-calling: `Hubs/Model_Context_Protocol.md` and `Hubs/Agent_Tool_Calling.md`
   - Evals: `Hubs/LLM_Evals.md`

## Useful Resources

- `Assets/Tool_Calling_Experiment_Lab.md`: prompts and experiments for building better tool-calling systems.
- `Assets/CLI_Playbook.md`: search the vault with `rg` from your terminal.
- `AGENTS.md`: how to ingest transcripts, docs, papers, and repos into the graph.
- `CONTRIBUTING.md`: how to suggest additions through GitHub.

## What To Post In The Community

When you use the graph, post:

- The concept or tool you studied.
- The production problem it helped you understand.
- One question or implementation tradeoff you still have.

This keeps the community focused on real engineering skill: not just collecting notes, but connecting concepts to production decisions.
